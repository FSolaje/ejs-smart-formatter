# 📚 Reglas de Gobernanza y Especialización del Agente

Este directorio contiene las reglas operativas y de contexto para el agente de IA:

- **`AGENTS.md` (Constitución Global Inmutable):** Define las normas transversales de seguridad (SAS), Conventional Commits, ciclo de vida y hooks. Es inmutable en ramas secundarias y solo se actualiza desde `main`.
- **Reglas Contextuales Modulares (`*.md`):** Coloca en este directorio archivos Markdown con las directrices específicas de tu proyecto o rama técnica.

### Ejemplos de Reglas Modulares Futuras:
- `backend-api.md`: Convenciones de diseño REST, esquemas de validación y control de transacciones.
- `frontend-ui.md`: Sistema de diseño, tokens CSS, ergonomía y accesibilidad WCAG.
- `infraestructura.md`: Topologías de red, inventario de servicios y políticas de cortafuegos.
- `documentacion.md`: Estándares de redacción técnica y guías de estilo para MkDocs o Docusaurus.
